# Art direction comparison: B2B order workbench

## Context

A high-frequency operations team reviews exceptions, compares orders and approves or rejects changes. The repository has a component system but no established visual thesis.

## Visual Context Profile

- Product mode: Operate
- Audience: experienced operations staff
- Session: repeated short tasks and long queue sessions
- Density: dense, because comparison and next-task throughput matter
- Trust/risk: consequential; approvals and money-related data need clear status
- Brand: calm and credible, with modest differentiation
- Content: structured data, filters, tables and evidence
- Device: desktop-first responsive web
- Differentiation: product tool feel, not decorative SaaS

## Candidate directions

### A — Swiss Operational

Grid-led, left-aligned, border-led surfaces, restrained radius, low-chroma neutral plus one accent, compact tables and no decorative gradient.

### B — Humanist Enterprise

Same operational density, warmer neutral, softer type and moderate radius; imagery appears only in onboarding or educational empty states.

### C — Fluent Productivity

Layered neutral surfaces, stronger desktop shell and familiar productivity hierarchy; less visually distinctive.

## Selection

Choose A because the queue is comparison-heavy and users need low visual fatigue. Borrow Carbon-like table and state discipline from the system foundation, but keep the visual language Swiss. Reject B because warmth is useful for onboarding but would weaken the queue's scan rhythm. Reject C because the repository can reuse Fluent-like mechanics without making the brand visually dependent on them.

## Visual Grammar Contract

- Type: neutral grotesk UI roles with tabular numerics.
- Grid: fixed navigation plus fluid content; strong left alignment.
- Density: compact queue, standard detail panel.
- Color: low-chroma neutral, restrained action accent, independent success/warning/danger.
- Shape: restrained radius; capsules only for bounded filters and tags.
- Surface: flat and border-led; elevation only for overlays.
- Icons: one family with consistent optical weight.
- Motion: fast and functional for selection, save and panel continuity.

## Stress cases

Review long customer names, large totals, missing evidence, partial approval failure, permission denial, no results, many filters and narrow width before implementation.
