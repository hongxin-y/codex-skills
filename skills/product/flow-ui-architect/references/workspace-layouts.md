# Workspace Layouts

下面是常见复杂工作面的起点。它们不是模板库；必须回到任务关系、空间角色和生命周期做裁剪。

| 工作面 | 常用骨架 | 持久区域 | 按需区域 | 主要风险 |
| --- | --- | --- | --- | --- |
| IDE / 开发工具 | Three Pane + Command Bar | 文件树、编辑器、诊断 | 搜索、设置、扩展 | 面板挤压、焦点和键盘冲突 |
| 设计/视频编辑 | Canvas + Edge Tools + Timeline | 画布、时间线或图层 | 属性、资源、历史 | 工具浮层遮挡画布 |
| 数据分析 | Table/Chart Workbench | 数据表、筛选上下文 | 计算说明、字段配置 | 参考列丢失、横向滚动 |
| 客服/运营 | Queue + Master–Detail | 队列、当前对象、关键状态 | 历史、内部备注、批量工具 | 返回队列后丢筛选和草稿 |
| 文档/知识工作 | Document + Reference | 文档、目录或当前章节 | 评论、来源、版本 | 参考资料遮挡写作面 |
| AI 工作台 | Task Area + Evidence/Trace Panel | 主结果、输入、任务状态 | 推理证据、参数、历史 | AI 面板沦为装饰或阻碍任务 |
| 地图/监控 | Canvas + Status/Filter | 地图/画布、告警状态 | 详情、时间范围、图例 | 叠层遮挡热点和实时状态 |
| 电商/复杂筛选 | Results + Filter Drawer | 结果、排序、选择 | 过滤条件、对比 | 移动端筛选状态不透明 |
| 复杂表单 | Stepper/Sections + Summary | 当前输入、保存状态 | 帮助、预览、条件字段 | 自动折叠丢失错误和输入 |

对选中的工作面写出：为什么适合当前任务、哪些区域保持持久、哪些区域按需出现、如何在窄屏转化，以及哪种相邻工作面被拒绝。
