# User Perception and Visual Decisions

视觉决策可以使用用户心理假设，但不能把猜测写成事实。每条假设都要关联到角色、任务、风险和可观察的行为信号，并记录反例与验证方式。

## 1. 决策记录格式

```text
psychological hypothesis → observable signal → visual/interaction response
→ counter-risk → verification method
```

例：`高风险审批者需要先确认“这件事是否安全” → 反复查看金额、收款人和权限 → 固定显示身份/金额/审计状态，减少装饰动效 → 信息太多会拖慢批量扫描 → 用长列表、异常状态和键盘路径复核`。

## 2. 常见心理目标与视觉响应

| 心理目标（假设） | 可观察信号 | 可考虑的视觉/空间选择 | 反风险 |
| --- | --- | --- | --- |
| 降低不确定性 | 用户频繁寻找状态、来源、下一步 | 明确层级、持续状态、来源/更新时间、稳定锚点 | 状态过多造成噪声 |
| 提高控制感 | 用户频繁撤销、返回、调整筛选 | 可逆动作、明确 preview、保留选择/草稿、可见关闭 | 控制项淹没主任务 |
| 快速建立熟悉感 | 新手依赖标签、示例和帮助 | 识别优先于回忆，使用熟悉组件和清楚命名 | 过度追随惯例而失去产品语义 |
| 支持专家速度 | 高频用户连续扫描和批量处理 | 稳定网格、可预测快捷键、密度由任务证明、行级操作 | 密度过高导致误读和疲劳 |
| 感到安全、可信 | 用户停留查看权限、金额、出处 | 克制表面、明确语义色、证据和审计状态、少用突发动效 | 看起来“严肃”但操作仍不清楚 |
| 鼓励探索 | 用户浏览、比较、试错 | 可发现的预览、分组、适度对比和渐进展开 | 装饰和动效分散任务 |
| 感到完成和反馈 | 用户需要确认动作是否生效 | 就地反馈、进度和结果摘要、下一步入口 | Toast 瞬间消失导致不确定 |

这些是设计假设，不是跨文化或跨人群的普遍心理定律。颜色、圆角、阴影和动效不能单独保证信任、愉悦或转化。

## 3. 把“审美”变成任务决策

- **克制**：高风险、长会话和高密度任务优先减少装饰竞争；把视觉差异用于层级、状态和方向。
- **亲和**：低风险、探索和消费任务可使用更高的形状/色彩温度，但关键动作仍需稳定可辨。
- **权威**：使用清楚的结构、来源、数字处理和状态语义，不等于堆深色、阴影或大标题。
- **实验性**：只在产品需要探索或品牌识别时增加新奇构图；先保证返回、恢复和任务入口。
- **系统原生**：在已有平台或设计系统中保留交互预期，把差异放到语义、内容、密度和少量品牌节点。

## 4. 选择前的反证

每个重要视觉选择都回答：

1. 它帮助哪一个用户在什么任务阶段更快理解或更安全行动？
2. 哪些人会被它误导、排斥或增加认知负担？
3. 去掉它后任务是否变差？如果没有，删除或降低权重。
4. 是否有更熟悉、更可访问或更少遮挡的表达？
5. 如何用真实内容、错误、长会话和窄屏验证？

将“看起来更高级”“更有冲击力”“更像 AI”改写为上述可观察问题。无法给出任务证据时，把它记录为低置信度假设，并限制它影响的范围。
